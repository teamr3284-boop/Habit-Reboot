# Habit Reboot 🚀

Habit Reboot is a **modern AI-powered habit tracking web application** that helps users build consistency, track progress, and improve productivity through smart insights.

Users can **create habits, track streaks, log their daily mood, and receive AI-generated advice** based on their performance and emotional state.

---

## ✨ Features

### 📋 Habit Tracking
- Add and manage daily habits
- Mark habits as completed
- Delete habits
- Track habit streaks

### 🔥 Streak System
- Automatically tracks consecutive completion days
- Streak resets when a habit is missed
- Encourages long-term consistency

### 😊 Mood Check-In
- Daily mood logging using emoji
- Helps analyze productivity vs emotional state

### 📊 Progress Tracking
- Shows daily habit completion percentage
- Visual progress bar for motivation

### 🤖 AI Coach
- AI analyzes recent activity logs
- Provides personalized productivity advice
- Helps users improve their routine

### 🔐 Authentication
- Secure signup and login
- User-specific habit data
